# 🌍 Wanderlust

Wanderlust is a full-stack travel and property listing web application that allows users to explore vacation properties, view property details, create their own listings, and share reviews.

## ✨ Features

- 🔐 User Registration & Login
- 🏠 Create Property Listings
- ✏️ Edit & Delete Listings
- 🔍 Browse Available Properties
- 📍 Location-based Property Information
- 🖼️ Property Image Upload
- ⭐ Reviews & Ratings
- 👤 User Authentication & Authorization
- 📱 Responsive User Interface
- 🗺️ Interactive Maps
